## Documentation Scope

These documents focus on **how the system is designed and how the pieces interact**. They intentionally exclude:

- Deployment specifics, infrastructure configuration, or hosting details
- Credentials, API keys, environment values, or any secrets
- Internal operational notes

For local setup and configuration, see the [main README](../README.md).
